# Invocation Contract

Skill frontmatter descriptions are the primary discovery surface. An explicitly named or confidently matched Skill runs directly; `use-coding-skills` is optional guidance for ambiguous multi-stage requests.

One primary Skill owns the response. Session, discipline, policy, tool, and review-component Skills may contribute bounded overlays. The active coding agent owns ordering, evidence judgment, conditional review, adjudication, and the final response; Skill categories do not grant lifecycle authority.

Standalone review accepts one bounded target and never creates missing design, plan, or implementation work. Review evaluators are optional, read-only helpers discovered by their own descriptions.
